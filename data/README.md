# Data

- **Ninapro** — public EMG dataset. DO NOT COMMIT (it's huge). Use `fetch_ninapro.sh`.
- **Own captures** — our labeled multi-channel EMG (captured during Act 2). Small
  enough to commit, or use Git LFS if it grows.

Keep a clear schema: one folder/file per capture session, with metadata
(subject, gestures, channel layout, sample rate, date).
